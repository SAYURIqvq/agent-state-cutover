硬切上下文流程 / Hard Context Cutover

主线从上到下看：模型只拿当前需要的信息执行一步，产出状态补丁；程序校验补丁，合法就写入 State，同时把原始证据放进 Archive；窗口快满时生成 Checkpoint，新窗口加载它继续。

State 状态

当前事实表。保存 step、环境、约束、server_ip 等下一步必须知道的信息。

Note 笔记

恢复任务用。记录已完成、待完成、下一步、重要提醒。

Archive 原始存档

完整证据库。用户原话、工具返回、错误日志、文件修改、状态补丁都追加保存。

1

加载当前状态 / Load Current State

不读完整历史，只读 State 投影 + Note + 少量 Archive 指针。

2

执行一步任务 / Execute One Step

Agent 根据当前最小充分信息推理，调用工具，得到工具结果。

3

生成状态补丁 / Produce State Patch

模型不重写完整 State，只输出本轮改变了哪些字段。

4

校验补丁 / Validate Patch

程序检查字段名、类型、枚举、业务约束。合法才允许提交。

5

提交状态 / Commit State

合法 patch 合并进 State；工具结果和 patch 追加写入 Archive。

6

状态投影 / State Projection

从 Global State 里挑出下一步真正需要的字段，形成干净上下文。

7

硬切窗口 / Hard Cutover

Context 快满时生成 Checkpoint，新窗口加载它继续。

拒绝重试 / Reject Retry

如果 patch 写了未知字段、类型错误或违反约束，State 不变，要求模型重新输出。

Checkpoint 检查点

新窗口启动包：State Projection + Note + Archive 指针。
