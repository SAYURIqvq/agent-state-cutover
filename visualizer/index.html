Agent State Cutover Flow

A long-running agent survives context limits by writing durable state, notes, and archive events, then starting the next window from a compact checkpoint.

1. Current Window

The agent reads the current projection, reasons, and performs one unit of work.

context

2. State Patch

The model proposes only the fields changed by this round: set, append, or unset.

minimal mutation

3. Schema Validation

The program checks field names, value types, enums, and operation overlap.

guardrail
tool result patch validate merge append project

4. Global State

The validated patch merges into the durable current facts stored outside the model.

state.json

5. Archive

Raw events are appended for traceability without loading every event into context.

archive.jsonl

6. Checkpoint

A new window starts from state projection, notes, and recent archive pointers.
